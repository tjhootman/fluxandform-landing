# Self-hosted fonts

All fonts here are self-hosted and served same-origin. The site makes **no
third-party font requests** (BRIEF §3, §9).

## CommitMono-Regular.woff2

- **Font:** Commit Mono, Regular (weight 400), Latin subset.
- **Designer:** Eigil Nikolajsen.
- **License:** SIL Open Font License, Version 1.1 — see `CommitMono-OFL.txt`
  (copied verbatim as the author distributes it).
- **Source:** https://commitmono.com · https://github.com/eigilnikolajsen/commit-mono
  (woff2 obtained via the OFL-licensed `@fontsource/commit-mono` package).
- **Usage:** section labels, status badges, header meta line, footer only.

The OFL permits redistribution (including in this public repository) provided the
font is not sold on its own and the license text ships alongside it — both hold.

## Fraunces-Display.woff2

- **Font:** Fraunces — a **static instance** pinned at `opsz 144 · wght 400 ·
  SOFT 0 · WONK 0` (display optical size, regular weight, no softening, no wonk).
  Instanced from the variable font with fontTools so no unused axes ship.
- **Designers:** The Fraunces Project Authors (Undercase Type).
- **License:** SIL Open Font License, Version 1.1 — see `Fraunces-OFL.txt`.
- **Source:** https://github.com/undercasetype/Fraunces
  (variable woff2 obtained via the OFL-licensed `@fontsource-variable/fraunces`).
- **Usage:** the hero headline only. Nothing else on the site.

The OFL covers subsets and instances, so this pinned instance is redistributable
here under the same terms.
