// how_it_works

Four Steps

No accounts for guests. No downloads to vote. Scan a code and you're in.

> 01

HOST_STARTS_ROOM

Open VibeDeck, sign in with Apple Music, and spin up a party room. You get a share code and a QR.

> 02

GUESTS_SCAN_CODE

Everyone scans the code to join instantly — no app install required to get in the room and start voting.

> 03

CROWD_VOTES

Guests add tracks and spend vibes to vote. Want a song bumped up the queue? Rally the room behind it.

> 04

QUEUE_REORDERS_LIVE

The queue re-sorts in real time as votes land. The most-wanted track always plays next. The crowd decides.

// the_system

Built For The Party

Live Queue

Everyone sees the same queue update the moment a vote lands. No refresh, no lag — the room moves together.

The Vibe Economy

Every guest gets vibes to spend. Add a track, upvote a banger, or drop a super-vote to force a song up the line.

Apple Music

Full catalog search and real playback through the host's Apple Music. Real tracks, real sound, no clips.

Host In Control

The crowd suggests, the host commands. Play, pause, skip, and end the party stay in your hands at all times.
